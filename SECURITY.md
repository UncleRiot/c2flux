# Security Policy

## Supported Versions

c² flux is an independent, hobby-developed project maintained by a single developer.

Security fixes are generally considered for the latest published version only. Older versions are not actively maintained.

Security updates are provided on a best-effort basis. No guaranteed response times, update schedules, or long-term support commitments are offered.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it using GitHub's private vulnerability reporting feature.

Please do not disclose security vulnerabilities through public GitHub issues.

Reports will be reviewed on a best-effort basis. Confirmed vulnerabilities may be addressed in future updates, depending on their severity and available development resources.
